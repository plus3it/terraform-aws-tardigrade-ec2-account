## Repository-specific

### Purpose

This Terraform module manages EC2 account-level settings. It takes a single optional `ec2_account` object input and sets EBS encryption by default (with an optional default KMS key), EBS snapshot block public access, AMI block public access, instance metadata defaults, and optional serial console access. The module has no outputs.
